# Hex Flow Connect - SPEC

## Q&A Discovery
- **Core fantasy:** One continuous stroke across a hex grid, connecting matching nodes.
- **10-second hook:** Draw a single line through colored hex nodes; bridges and blockers twist the path.
- **Return loop:** Daily seeded board + par mastery.
- **Session targets:** 30s (quick), 2m (standard), 5m (hard mode).
- **Skill vs luck:** 90/10 skill; seed is deterministic, path is pure logic.
- **Fail-state fairness:** Immediate path-break feedback, no hidden penalties.
- **Difficulty ramp:** Tutorial → 3x3 → 5x5 → 7x7.
- **Distinction:** Hex adjacency + single-stroke vs square clones.
- **Art scope:** Vector tiles, tiny font, no heavy animation.
- **Audio/feedback:** Subtle click/line sounds.
- **Performance:** 60fps, max 7x7 board.
- **Assumptions:** No server needed; local seed from date hash.

**USP:** Hex topology + single-stroke creates uniquely spatial reasoning vs square-grid clones.

**Differentiators:** (1) Hex adjacency logic, (2) Color-mixing bridges, (3) Daily seed mastery.
**Retention hooks:** Daily seed, par mastery, streak tracking.
**Quality bars:** Smooth draw, readable hex tiles, immediate feedback.
**MVP guardrail:** No multiplayer, no server sync, no ads (post-MVP).
